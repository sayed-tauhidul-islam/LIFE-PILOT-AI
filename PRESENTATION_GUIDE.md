## 🎨 RECOMMENDED DESIGN SYSTEM

### **Color Palette:**
```
Primary:     #3F51B5 (Deep Indigo)    [Main brand color]
Secondary:   #00BCD4 (Cyan)           [Accent color]
Accent:      #FF9800 (Orange)         [Call-to-action]

Warning:     #FFC107 (Amber)          [Caution/alerts]

Background:  #F5F5F5 (Light Gray)     [Slide background]
Text:        #212121 (Dark Gray)      [Body text]
Light BG:    #FFFFFF (White)          [Content areas]
```

### **Typography Guidelines:**

```
Headlines (Slide Titles):
  Font: Plus Jakarta Sans (Bold)
  Size: 48-56px
  Color: #3F51B5
  Spacing: 1.2 line-height

Subheadings:
  Font: Plus Jakarta Sans (SemiBold)
  Size: 28-36px
  Color: #00BCD4
  Spacing: 1.3 line-height

Body Text:
  Font: Inter (Regular)
  Size: 18-20px
  Color: #212121
  Spacing: 1.5 line-height

Code/Technical:
  Font: Courier New (Monospace)
  Size: 14px
  Color: #333333
  Background: #F5F5F5
```

### **Layout Guidelines:**

```
Margins:
- Top: 40-50px
- Bottom: 40-50px
- Left: 60-80px
- Right: 60-80px

Column Layout:
- Single column: Full width - 60 margin
- Two columns: 45% + 45% (10% gap)
- Three columns: 28% + 28% + 28% (8% gaps)

Image Sizing:
- Hero images: Full width with 20px padding
- Feature icons: 80-100px (consistent)
- Logos: 60-80px height (maintain aspect ratio)

Spacing Between Elements:
- Between sections: 30-40px
- Between features: 20-30px
- Between bullets: 15-20px
```

## 🎤 PRESENTATION SPEAKING TIPS

### **Before You Present:**

```
Practice:
✅ Practice out loud 3-5 times
✅ Time yourself (aim for 10-12 minutes)
✅ Record yourself and watch
✅ Practice with actual slides
✅ Refine based on feedback

Prepare:
✅ Have speaker notes (not visible)
✅ Test audio/video demos beforehand
✅ Have backup (PDF + offline copy)
✅ Charge all devices
✅ Test internet connection

Appearance:
✅ Dress professionally/business casual
✅ Get good sleep before
✅ Eat before presenting
✅ Stay hydrated
✅ Test microphone (if remote)
```

### **During Presentation:**

```
Delivery:
✅ Make eye contact with audience
✅ Speak clearly and at normal pace
✅ Use hand gestures naturally
✅ Pause after important points
✅ Don't read slides word-for-word
✅ Show enthusiasm and passion
✅ Smile and maintain positive posture

Engagement:
✅ Ask rhetorical questions
✅ Use storytelling elements
✅ Reference audience/their problems
✅ Include data and statistics
✅ Show live demos
✅ Make it personal
✅ Connect emotionally
```

### **Presentation Structure (Story Arc):**

```
Open (Hook):
- Start with a problem or statistic
- Ask an engaging question
- Tell a brief relevant story
- Show something surprising

Build Interest:
- Explain the problem deeply
- Show why current solutions fail
- Build urgency/importance
- Make audience care

Present Solution:
- Introduce your product
- Show how it solves the problem
- Demonstrate with examples
- Prove it works

Call to Action:
- Tell them what to do next
- Make it easy and clear
- Create urgency
- Provide multiple contact options
```

### **Handling Questions:**

```
Best Practices:
✅ Listen fully before answering
✅ Rephrase the question
✅ Pause before responding
✅ Admit if you don't know
✅ Offer to follow up
```
